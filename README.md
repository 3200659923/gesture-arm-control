# 基于 MediaPipe 视觉手势识别的 STM32 机械臂控制系统

## 项目简介

本项目实现了一套完整的**视觉手势控制机械臂系统**。通过 USB 摄像头采集人手图像，利用 Google MediaPipe 进行 21 个手部关键点实时识别，将手掌位置和手势映射为 4 路舵机角度，通过蓝牙无线通信发送给 STM32 下位机，驱动机械臂跟随人手运动。

## 系统架构

```

│  └──────────┘   └──────────┘   └──────┬───────┘ │
│                                      │         │
│                              ┌───────▼───────┐ │
│                              │  串口/蓝牙发送  │ │
│                              └───────┬───────┘ │
└─────────────────────────────────────┼─────────┘
                                      │ 蓝牙无线
┌─────────────────────────────────────┼─────────┐
│                 下位机 (STM32)       │         │
│                              ┌───────▼───────┐ │
│                              │ 串口接收+解析  │ │
│                              │ I2C → PCA9685 │ │
│                              └───────┬───────┘ │
└─────────────────────────────────────┼─────────┘
                                      │ PWM
                              ┌───────▼───────┐
                              │   4自由度机械臂  │
                              │ 底座/大臂/小臂/夹爪 │
                              └───────────────┘
```

## 功能特性

### 视觉识别（上位机）
- ✅ MediaPipe Hands 21 个手部关键点实时检测
- ✅ 手掌位置识别（左右/上下/远近）
- ✅ 手势识别（握拳/张开）
- ✅ 指尖距离判断（抗手腕倾斜干扰）
- ✅ 3 帧多数投票防抖
- ✅ 指数平滑消除舵机抖动
- ✅ 死区过滤避免微抖动

### 机械臂控制
- ✅ 4 自由度：底座旋转、大臂俯仰、小臂俯仰、夹爪开合
- ✅ 角度限幅保护（防止撞支架）
- ✅ 抓取锁定模式（握拳后锁定夹爪，抬升时不会掉落）
- ✅ 蓝牙无线通信（10m 范围）

### 扩展功能
- 🔄 橙色物体识别（HSV 颜色追踪）
- 🔄 坐标标定工具
- 🔄 交互式启动器（自动扫描串口/摄像头）

## 通信协议

```
格式：Axx,Bxx,Cxx,Dxx\n
示例：A90,B120,C45,D0\n
```

| 字段 | 含义 | 范围 |
|---|---|---|
| A | 底座旋转角度 | 5~175° |
| B | 大臂俯仰角度 | 10~170° |
| C | 小臂俯仰角度 | 0~120° |
| D | 夹爪开合角度 | 0~90° |

波特率：115200，8N1

## 关键算法说明

### 1. 指尖距离判断张开/握拳
计算 5 个指尖之间的平均距离与手掌长度的比值：
- 比值 < 0.9 → 握拳（夹爪闭合）
- 比值 > 0.9 → 张开（夹爪打开）

优势：不受手腕倾斜角度影响，识别稳定。

### 2. 指数平滑
```
角度 = 上次角度 × (1-α) + 当前角度 × α
```
α=0.3，消除单帧抖动，舵机运动平滑。

### 3. 抓取锁定状态机
- 未锁定 → 检测到握拳 → 锁定（夹爪闭合）
- 已锁定 → 检测到张开 → 解锁（夹爪打开）

防止抬升过程中因识别误差导致物体掉落。

## 技术亮点

1. **软硬结合**：PC 端视觉识别 + STM32 实时控制
2. **无线通信**：蓝牙 SPP 透传，摆脱线材束缚
3. **抗干扰设计**：多层防抖（投票+平滑+死区+锁定）
4. **安全保护**：软件角度限幅，防止舵机堵转烧毁
